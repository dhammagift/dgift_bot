# unused/

Файлы, про которые подтверждено, что продовый код их не использует.
Не удалены — перенесены сюда, чтобы можно было свериться со старым поведением.

- `botRest.py` — самодельный watchdog-автоперезапуск: следил за
  `/var/www/telegram_bot/bot.py` и перезапускал процесс при изменении файла.
  Мёртвый по двум причинам: (1) такого `bot.py` в репозитории нет, точка входа —
  `main.py` с путём к конфигу аргументом (см. `setup.sh`,
  `install_sysctl_bots.sh`); (2) перезапуск в проде делает systemd
  (`Restart=always` в юнитах из `install_sysctl_bots.sh`). Ничто в репозитории
  его не импортирует и не запускает. Не путать с `watcher.py` — тот живой,
  цепляется к боту через `post_init` в `main.py` и следит за `WATCH_DIR`
  (новые файлы отправляются админам), к перезапуску процесса отношения не имеет.
